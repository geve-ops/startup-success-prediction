# Startup Success Prediction (BAN1023A1)

Intro to Data Science project by Gerald Velas. Predicts whether a startup is successful (acquired/operating/IPO) or closed, using the Kaggle "Startup Success Prediction" dataset.

- `VELAS_BAN1023A1_FINAL_PROJECT.ipynb` - data cleaning, EDA, Logistic Regression and Random Forest models
- `BAN1023A1-Midterm-Presentation.pptx` - presentation

Results: Logistic Regression ~71% test accuracy, Random Forest ~70%.
